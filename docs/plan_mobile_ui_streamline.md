# 手机端 UI 与可靠性修复实施方案

## 定位与边界

本工具供个人使用，最多小范围共享。目标是在手机上可靠地选择拍摄内容、控制双机录停、查看和导出记录；不是企业平台或完整 GMP 合规系统。

沿用原生 HTML/CSS/ES Modules、现有 BLE 客户端和固件主账。保持既有控件 ID、三视图导航与设备协议。不增加框架、自动重试层、云服务、震动/声音或透明 Switch。手机页面并非由当前 C3 固件的 LittleFS 提供；不为网页压缩调整固件或主账分区。

本文件替代前版未经验证的“零滚动、全阶段放行”承诺。历史提交 d3aa7d5 的 60 项 Node 测试通过，不代表移动布局、Bluefy 保活或异常恢复已通过。

## 用户可见契约

### 录停与同步

- 点击、请求、ACK 和观察到相机录像是不同事实，不可混用。
- 日志同步最多一个流；期间录停可操作，新增事件可通过合并后的尾随同步补齐。
- 缓存读取暂时失败后能再次同步；旧连接或旧项目的结果不得覆盖当前项目。
- 结束落盘存在 closing 阶段；最终转 idle 后，手机应取得已提交 END。
- ready 是开录准入状态，不能因正常录像时 ready=false 而报警。

### 模板、点位与导出

- 历史点位只补入身份相符的本地模板，按设备契约恢复合法编号。
- 新建表单保留原输入规则；恢复历史记录不能套用更窄的新建规则。
- 本地保存失败保留输入并明确提示，不能报告成功或继续设备选中。
- 本地添加成功而设备选中失败，明确区分“已添加”和“未选中”。
- 当前动作的任意孤儿点位均可从详情列表补中文名称，无须先改变设备点位；只修改字典，不改历史事件或发送选择命令。
- 名称输入限制与实际保存一致，不静默截断用户输入。
- 只有同一 boot 的非负单调区间可相减；最近一段和 CSV 共用判断，合法零区间保留为 00:00 / 0.0，跨 boot 时长未知。
- 现场秒表使用硬件单调时钟依据，不把单位未确认的相机计时数值当作秒数。

### 保活

- 重复状态更新不重复申请 WakeLock；停止、断连、销毁后的晚到申请须释放。
- 可播放媒体与实际保持亮屏是两项不同的验证。媒体必须完整，play 失败不能报告成功。
- 不支持保活时明确提示手动保持亮屏；不把浏览器 API 成功视为 Bluefy 真机验收。

## 布局与交互契约

正常字号优先让关键录停操作首屏可达；极小视口、大字或较长异常提示允许受控滚动保底，不能靠隐藏关键内容伪装零滚动。

- 顶部保留连接、项目、设置、演示说明及必要的跨页录停状态；反馈始终参与正常流，不覆盖顶栏。成功反馈 2 秒后消失，真实账本失败保留摘要和完整详情入口。
- 移动根按反馈、工作台两行布局；工作台按概览、内容、导航三行布局。反馈隐藏时该行归零，安全区和左右边距只计一次。
- 正常现场页按相机观察滚动区、当前动作、录停区三行布局；当前动作紧邻录停，相机详情展开不移动这两个区域。
- 动作与录停高度加八个根字号超过现场可用高度时，切为整个现场页滚动；八个根字号是观察区预算，不是固定高度小窗。
- 两机共用一层轻底色、细边框和中线，内部详情单列；记录列表保持分隔线，仅更正表单增加局部轻分组，不恢复多层 Bento。
- 根字号为 100%，支持时渐进增强为 `font:-apple-system-body`，界面字号采用 rem；不禁止缩放，触控目标至少 `max(48px,3rem)`。
- 动作名最多两行、点位摘要单行省略，详情保留完整文本；省略不改变存储内容。
- 选机共用滑块只跟随确认值，pending/拒绝不提前移动。最近一段区分身份、控制器区间时长和结果，“改归属”直接打开原编辑面板。
- 设置、新增/补名、只读详情共用三个原生 dialog 的生命周期；退出期间保留模态，Esc、取消、遮罩、手柄共用关闭路径，焦点恢复到可用入口。设置从三视图打开均不改变原视图和草稿，不自动弹出。
- 根据 VisualViewport 的可见高度和偏移避让键盘；仅手柄处理下滑关闭，不能劫持表单滚动、文字选择或缩放。
- 首页步进使用完整稳定排序清单，不受清单页筛选影响；首尾不回绕。区域、类型、记录状态和搜索独立组合并跨页保留。
- 清单/记录页保留真实拍摄阶段和直接停止入口；等待 ACK 不等于已观察录像，跨页 STOP 复用原单飞和项目/段身份保护。
- 断连或不满足编辑条件的控件禁用；未结束片段不可改归属。“标记不用”是可逆标记，不删除素材或改变录制阶段。
- 最近摘要、记录行和 CSV 共用同 boot 非负控制器区间判断；合法零区间保留，未知时长不伪造，不宣称视频文件时长。

### 实现者共享 DOM

`#card-record-ledger` 的直接子块依次为 `#shoot-scroll-area`、
`#card-current-action`、`#shoot-record-controls`；上方滚动区只包含相机观察信息。
`#card-connection` 移入 `#modal-settings`，原控件不复制。
`#global-record-strip` 位于 `#topbar-summary` 内，提供跨页状态和 `#btn-global-stop`。
`#bottom-view-nav` 留在 `main.workbench-shell` 内、`workbench-columns` 之后。
三个 dialog 共用 `--sheet-viewport-height`、`--sheet-viewport-top` 和同一关闭/焦点清理路径。

## 验收

### 自动化与专项行为

执行 `node --test tests/test_phone_ui.mjs tests/test_phone_client.mjs`。回归关注真实失败路径：同步失败恢复、尾随与录停穿插、延迟保活申请、身份匹配和持久化失败、孤儿补名、跨 boot 导出及异步结案。

仅对没有覆盖的真实行为增加永久用例，不测试文案、纯转发或 mock 回声；不以测试数量作为质量目标。

### 实际页面

检查 375×548、375×667、390×844、440×956、844×390、1024×768、1280×800。覆盖明暗色、125%/150%/200% 字号、加倍行高、长名称、异常提示、相机详情、三视图及原生抽屉。必须实际滚动并测按钮中心命中，不能只看截图或根宽度。

浏览器布局检查不能由 JSDOM 的 DOM 属性断言替代；根页面没有滚动条也不能证明内部无裁切。

### 真机边界

iPhone/Bluefy 的软键盘、真实 BLE、后台恢复、3–15 分钟亮屏与实际手套操作需单独实测。没有设备证据时明确记为未验证，不宣称现场稳定版放行。不读取或修改相机既有素材，不重置设备主账。
